# Font Awesome

Interface icons are rendered with ProcessWire's native `wireIconMarkup()` helper
and the Font Awesome assets loaded by AdminThemeUikit. No separate icon font,
JavaScript icon library or CDN is bundled or requested by Workspace.

`../workspace.svg` renders the `th-large` (U+F009) glyph from Font Awesome 4.7
included in ProcessWire core's `wire/templates-admin/styles/font-awesome/`.
