# Changelog

All notable changes to Workspace are documented here.

## [1.0.0] - 2026-11-02

First release. Workspace has not had an earlier published release.

### Added

- Application launcher with search, Favorites and shared application navigation.
- Square application-switcher tiles on desktop and a single horizontally scrollable strip on phones.
- Workspace registry, ProcessWorkspace launcher and AdminThemeWorkspace in one package.
- Hook-based registration for independently installed site Process modules.
- Optional compatibility integrations for Kontor, Mercato, Mailbox, Dispatch, Files and Tickets.
- Permission-aware application discovery and server-side operator restrictions independent of theme.
- Administrator-only technical configuration routes and native administrator sign-in flow.
- Light, Dark, System and Black appearance, nine palettes, six local font stacks, text scaling and contrast controls.
- Native ProcessWire Font Awesome icons, application-registration documentation, examples and verification tools.
- Native ProcessWire localization for PHP screens, accessibility labels and dynamic browser messages, with provider-owned application translations.
- Isolated shell controls from delayed application button enhancement and kept the account Appearance label visible inside applications.
