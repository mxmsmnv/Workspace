# Workspace

One installable ProcessWire application shell for Kontor, Mercato, Mailbox, Dispatch, Files, Tickets. PHP 8.2+, ProcessWire 3.0.244+, AdminThemeUikit compatibility. Keep all business operations owned by their applications. No production installs or real mail/payment actions. Do not store secrets or fixture data in Git. Prefer native forms/assets internally, custom app-only navigation externally. No technical Pages/Templates/Modules navigation for workspace operators; server authorization is independent of theme.

You are not alone in the codebase. Preserve other workers changes. Own only assigned files.
