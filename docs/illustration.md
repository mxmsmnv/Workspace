# README illustration

`assets/Workspace.png` was generated with the built-in imagegen tool for
Workspace 1.0.0. The repository had no earlier README doodle.

The scene is based on the indexed module files, registry/access/presentation
traits, built-in application descriptors, launcher/theme templates and
appearance controls: independent business apps arranged in one shared shell,
an additional connected app, and a palette symbol. It is an editorial
illustration, not a screenshot or a claim about an additional installed app.

## Final generation prompt

Use case: illustration-story. Asset type: README hero illustration for Workspace,
a ProcessWire application launcher and shared app shell. Primary request:
Minimalist playful hand-drawn doodle illustration, black ink line art, simple
abstract human characters, expressive body poses, pastel background shapes,
white background, loose imperfect sketch lines, modern editorial illustration
style, fun and friendly, flat colors, clean composition. Scene informed by the
actual repository: a friendly abstract person arranging independent app tiles
into one shared workspace, another person connecting a new tile with a small
connector line to represent extensible hook-based registration. Tiles carry
simple outline symbols for a briefcase, shop, envelope, paper plane, folder and
support ticket. One small palette symbol suggests shared appearance settings.
Wide landscape editorial composition, generous white space, restrained pastel
lavender, mint and peach. No text, no letters, no logos, no watermark, no
photorealism.
